# Markdown Text Formatting Helper

> I like creating .md files for myself to learn and evolve as a programmer.
> 
> This .md file is created as I was tired of having to look up .md formatting codes. It should act as a lookup
> .md helper instead of having to use StackOverflow or AI for basic text formatting in .md files.

___

## Section Formatting

Use these for section formatting

> - **Line Change:** Use 3 x "-" or "_" for line change

___

## Text Formatting

Basic Text Formatting codes for .md text visuals

> - **Bold Text** | __Bold Text__
> - *Cursive Text* | _Cursive Text_
> - ***Bold & Cursive***
> - ~~Line Through~~
