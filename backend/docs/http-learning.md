## Cheat Sheet for HTTP codes

> I like creating notes for my self in order to learn more efficiently. This one is for HTTP Codes.

___

### 200 [Success]

- 200 - OK
- 201 - Created
- 202 - Accepted
- 204 - No Content

___

### 300 [Redirection]

- 300 - Multiple Choices
- 301 - Moved permanently
- 302 - Found
- 304 - Not modified

___

### 400 [Client]

- 400 - Bad request
- 401 - Unauthorized
- 403 - Forbidden
- 404 - Not found
- 409 - Conflict
- 422 - Validation failed

___

### 500 [Server]

- 500 - Internal server error
- 501 - Not implemented
- 502 - Bad gateway
- 503 - Service unavailable
- 504 - Gateway timeout
